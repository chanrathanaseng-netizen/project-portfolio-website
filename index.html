Network Engineering and VLAN Configuration

Design and configure a structured network environment using routers, switches, VLAN segmentation, and inter-VLAN routing.

  • Configure Cisco switches (PNCSWX) & routers (PNCRX)
  • VLAN 10 (Staff), 20 (Server), 30 (IT), 99 (Management)
  • Subnetting 10.X.X.0/23 into scope capacities
  • Router-on-a-stick 802.1Q tagging & DHCP scope pools
In Progress SNAC Term 2

Windows Server 2022 and Active Directory

Install and configure Windows Server as the central identity, DNS, and file-sharing service for the project environment.

  • Promote host DC0X to Domain Controller (groupname.local)
  • Configure DNS, PTR records & Active Directory DS
  • Department share permissions (Data: Read, Global: Modify)
  • Join client machines to domain & test policy enforcement

METHODOLOGY

Our Project Workflow

Structured steps followed during the design, implementation, and maintenance phase.

STEP 01

Plan

Review specs, calculate subnet capacities, and agree on topology.

STEP 02

Configure

Set hostnames, VLAN trunks, routing interfaces, and IP scopes.

STEP 03

Deploy

Spin up server VMs, domain controllers, and web/database software.

STEP 04

Secure

Apply UFW firewalls, SSH key locks, and file share user permissions.

STEP 05

Test

Verify inter-VLAN ping, domain joining, DNS lookups, and web access.

STEP 06

Document

Record IP tables, credentials, and step-by-step troubleshooting logs.

STEP 07

Backup

Export SQL databases, snapshot VMs, and conduct restore drills.
